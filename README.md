# Universal Shop

Универсальный интернет-магазин на Node.js + Express + Prisma + SQLite.

## Установка

    npm install
    npm run migrate
    npm run seed
    npm run dev

http://localhost:3000 — Админ: `admin@shop.local` / `admin123`
